# Contributing to Trajecto

Thank you for your interest in contributing to **Trajecto – Train Ticket Reservation System**!

We welcome contributions from developers who want to improve the project, fix bugs, enhance the UI, or introduce new features.

## Getting Started

1. Fork the repository.
2. Clone your fork to your local machine.

   ```bash
   git clone https://github.com/YOUR-USERNAME/Trajecto.git
   ```

3. Navigate to the project directory.

   ```bash
   cd Trajecto
   ```

4. Create a new branch for your contribution.

   ```bash
   git checkout -b feature/your-feature-name
   ```

## Contribution Guidelines

- Follow the existing project structure and coding conventions.
- Write clean, readable, and maintainable code.
- Test your changes before submitting them.
- Avoid committing unnecessary files or build artifacts.
- Provide clear descriptions of your changes.
- Ensure that your changes do not break existing functionality.

## Submitting Changes

1. Make your changes in your local repository.
2. Stage your changes.

   ```bash
   git add .
   ```

3. Commit your changes.

   ```bash
   git commit -m "Add: describe your contribution"
   ```

4. Push your branch.

   ```bash
   git push origin feature/your-feature-name
   ```

5. Open a Pull Request against the main branch of the original Trajecto repository.
6. Provide a clear explanation of your changes and wait for review.

## Reporting Bugs

If you discover a bug, please open a GitHub Issue with:

- A clear description of the problem.
- Steps to reproduce the issue.
- Expected behaviour.
- Actual behaviour.
- Screenshots or error logs, if applicable.

## Feature Requests

We welcome new ideas and feature suggestions. Open a GitHub Issue describing the proposed feature and its potential benefits.

## Code of Conduct

Be respectful, collaborative, and constructive when interacting with other contributors.

Thank you for helping improve Trajecto!
